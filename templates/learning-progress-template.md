# My AIPE Academy learning record

The companion command keeps the machine-readable record in
`learning/progress.json` and renders this Markdown view from it
(`python skills/aipe-academy/scripts/academy.py record ...`). Both live in the
git-ignored `learning/` folder and are never committed. When no command is
available, fill this template by hand.

Use `not_started`, `learning`, `needs_review`, or `demonstrated`. Record
`demonstrated` only for a task solved independently with an explained changed
condition; assisted work is `learning` or `needs_review` and is repeated with a
fresh task. Leave fields unknown until the learner supplies information or
completes work.
