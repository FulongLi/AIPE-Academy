# Working in AIPE Academy

Determine the user's intent before acting:

- For repository development, research, editing, or review, carry out the requested work. Do not start a tutoring interview with the maintainer.
- For a request to learn with this repository, read `START-HERE.md` and `prompts/tutor-guide.md`. These define the learning workflow; the learner does not need to write a detailed prompt.
- If a link is shared without a clear request, briefly explain that this is a guided learning repository and ask whether the user wants to start learning or inspect the project.

Keep university course facts separate from AIPE Academy's proposed adaptations. Record source URLs, course edition/term, access limitations, and verification dates. Do not describe a course outline as a completed lesson or claim to have read unavailable attachments.

Use original exercises and explanations. External materials retain their own licenses. Save personal learning records locally; do not publish or commit them as part of routine curriculum work.
