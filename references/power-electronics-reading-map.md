# Power Electronics Reading Map

This file records how Spirit Connect Academy relates to established power electronics learning resources.

The main technical inspiration for this track is:

- Robert W. Erickson and Dragan Maksimovic, *Fundamentals of Power Electronics*, 3rd edition, Springer, 2020.

Use the book as a rigorous reference. Use this repository as an open, AI-guided learning path.

## How This Project Should Use References

- Do not copy textbook chapters, examples, figures, or problem statements.
- Do create original explanations, simulations, diagrams, prompts, and projects.
- Do cite sources when a topic is clearly inspired by a specific reference.
- Do separate beginner orientation from advanced derivation.
- Do translate advanced ideas into learning paths, not shortcuts that hide important assumptions.

## Book-Inspired Knowledge Areas

The academy track should gradually cover these areas in original form:

- introduction to power conversion
- steady-state converter analysis
- losses, efficiency, and equivalent circuit thinking
- practical switch realization
- discontinuous conduction mode
- converter topologies
- averaged modeling and AC equivalent circuits
- converter transfer functions
- controller design
- magnetics and magnetic component design
- design-oriented analysis
- input filter design
- current-programmed control
- digital control
- rectifiers and harmonics
- resonant conversion and soft switching

## Spirit Connect Academy Translation

The academy should translate rigorous references into:

- beginner maps
- prerequisite bridges
- small simulations
- design notebooks
- AI tutor prompts
- project briefs
- self-check questions
- open contribution tasks

The north star is simple: help learners move from confusion to capability.
